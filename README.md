# 📝 Gestor de Notas

Aplicación de consola desarrollada en Python para registrar, guardar y analizar notas de estudio.

Permite cargar notas, verlas, calcular el promedio y almacenar los datos en un archivo de texto para no perder la información al cerrar el programa.

---

## 🚀 Funcionalidades

- Agregar notas
- Ver todas las notas cargadas
- Calcular promedio
- Borrar última nota
- Guardado automático en archivo `notas.txt`
- Menú interactivo por consola

---

## ▶️ Cómo ejecutar

Abrir la terminal en la carpeta del proyecto y ejecutar:

python gestor_notas.py
